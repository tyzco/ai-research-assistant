# PaperLink 演示脚本 (5 分钟)

> 适用于面试视频录制。每步标注时间、画面、操作、讲解词。

---

## 开场 (0:00-0:15)

**画面**: 浏览器打开 `http://localhost:8001/`，暗色主题、侧边栏有若干历史课题。

**操作**: 无。

**讲解词**:
> "这是 PaperLink，一个面向学术研究者的文献检索和深度问答工具。它集成了 12 个国际学术数据库的并行搜索，支持一键构建知识库，以及基于 RAG 的论文全文问答。"

---

## 步骤 1: 创建课题 + 多源搜索 (0:15-1:00)

**画面**: 在输入框输入 "计算机视觉"，按 Enter。顶栏出现绿色脉冲圆点 + 蓝色流光条，搜索骨架屏下方显示 12 个进度圆点逐一点亮。

**操作**: 输入 → 回车。等待 ~8s。

**讲解词**:
> "输入研究方向后，系统自动完成三件事：
> 1. 中文关键词提取并翻译为英文检索词（这里用的是 DeepSeek 轻量 LLM 翻译，字典作 fallback）
> 2. 并行向 12 个学术数据库发起搜索——arXiv、OpenAlex、Semantic Scholar、Crossref、CORE、DOAJ、Europe PMC、PubMed、PapersWithCode、Google Scholar、CNKI
> 3. 每篇论文标注 OA 开放获取状态，DOI 补全，摘要补全
>
> 可以看到顶栏的脉冲绿点表示搜索进行中，12 个圆点代表 12 个数据源逐个返回。"

---

## 步骤 2: 论文预览 + 下载引导 (1:00-1:45)

**画面**: 搜索完成，显示 159 篇论文。鼠标移到一篇论文上，点击标题打开右侧预览面板。展示摘要、作者、年份。然后展示下方的 PDF 获取引导栏。

**操作**: 点击一篇论文标题 → 展示预览面板。鼠标指向下载引导栏。

**讲解词**:
> "搜索结果按中文优先、OA 优先排序。点击论文标题可以预览摘要，点击"预览"按钮会打开右侧面板，对于 arXiv 论文还可以直接内嵌查看 PDF。
>
> 对于非 OA 论文，系统会生成 Sci-Hub 的直链。底部的引导栏提供了 Sci-Hub 主站和三个镜像链接，以及批量复制 DOI 的功能。
>
> 用户可以复制 DOI 到 Sci-Hub 批量下载，然后拖拽 PDF 到页面上传，系统会自动解析并构建知识库。"

---

## 步骤 3: PDF 上传 + 知识库构建 (1:45-2:15)

**画面**: 切换到已有知识库的课题（如"深度学习"），展示上次上传的 PDF 列表。直接在输入框提问。

**操作**: 点击侧边栏的已有课题 → 输入问题。

**讲解词**:
> "切换到已有知识库的课题。这里之前上传过几篇深度学习相关的论文。现在我可以直接对它们提问。
>
> 即使没有上传 PDF，系统也会自动找到已有的知识库来回答。这个设计避免了"必须先上传才能用"的糟糕体验。"

---

## 步骤 4: RAG 深度问答 (2:15-3:00)

**画面**: 在已有 KB 的课题中输入 "什么是深度学习"。系统显示检索过程，然后流式输出答案。答案包含引用标注。

**操作**: 输入问题 → 回车。等待 ~6s。

**讲解词**:
> "提问后，系统经过完整的 RAG 链路：
> - 意图分类（这是个"定义"类问题，跳过重排节省时间）
> - 查询改写（短查询直接检索）
> - 自适应混合检索——根据查询特征动态调整 BM25 和向量检索的融合权重
> - 级联重排——MiniLM 快速预筛后 bge-reranker 精排
> - DeepSeek 基于检索到的上下文生成答案
>
> 答案会标注引用的论文。这是用 SSE 流式返回的，用户不需要等完整答案生成。"

---

## 步骤 5: 流水线追踪 (3:00-3:30)

**画面**: 打开新标签页 → `http://localhost:8001/static/pipeline.html`。输入问题 "什么是机器学习"，点击追踪。左侧实时展示每步处理过程（查询改写→向量检索→BM25→RRF 融合→重排→生成），右侧显示耗时和得分。

**操作**: 打开流水线页面 → 输入问题 → 点击追踪。

**讲解词**:
> "这是为面试准备的流水线追踪页面。它用 SSE 实时展示 RAG 每一步的处理过程和耗时。
>
> 可以看到：查询改写耗时、向量检索命中了多少候选、最高相似度、BM25 关键词命中了多少篇、RRF 融合的权重分配（BM25 偏向还是语义偏向）、以及重排前后的数量变化。
>
> 这个页面在面试时用来展示你对 RAG 链路的完整理解。"

---

## 步骤 6: Agent 模式 (3:30-4:00)

**画面**: 回到主界面，勾选 Agent 模式。输入 "调研 Transformer 架构的主要变体"。系统显示 Agent 状态流转。

**操作**: 勾选 Agent → 输入问题。

**讲解词**:
> "Agent 模式基于 LangGraph 的 StateGraph 实现。它不再是简单的检索+生成，而是多步推理。
>
> Agent 可以自己搜索论文、下载、构建知识库、提问、生成报告。目前集成了 12 个工具，使用 OpenAI Function Calling 标准格式。
>
> 还有一个 Agent 监控面板，实时展示状态机的节点流转。"

---

## 步骤 7: 知识图谱 (4:00-4:30)

**画面**: 打开 `http://localhost:8001/static/kg.html`。D3.js 力导向图展示当前课题的论文节点和关联关系。点击节点查看详情，边高亮显示关联。

**操作**: 打开图谱页面 → 点击节点 → 展示关联关系 → 搜索过滤。

**讲解词**:
> "知识图谱是 PaperLink 的特色功能之一。从论文摘要中通过 LLM 自动抽取方法、数据集、指标等实体，建立论文间的关联关系。
>
> 点击节点可以查看论文详情和关系列表，点击关系可以跳转到关联节点。支持搜索过滤和缩放操作。
>
> 用户可以在搜索结果页勾选论文，一键添加到图谱中。"

---

## 步骤 8: 收尾 (4:30-5:00)

**画面**: 回到主界面，展示侧边栏的历史会话持久化、暗色模式切换、课题删除功能。然后打开 `/static/test.html` 展示 API 测试面板。

**操作**: 切换暗色模式 → 删除一个课题 → 新建课题 → 打开测试面板。

**讲解词**:
> "还有一些工程细节：
> - 会话持久化——重启后历史课题自动恢复
> - 暗色模式
> - 课题管理
> - API 测试面板——25 个端点全部有测试入口
>
> 项目由 17 个 Python 模块组成，约 5,400 行代码，25 个 API 端点，12 个搜索数据源，5 个可视化页面。
>
> 核心亮点是自研的自适应混合检索和级联重排——不是调 LangChain 的包，而是从特征工程层面优化检索质量。"
