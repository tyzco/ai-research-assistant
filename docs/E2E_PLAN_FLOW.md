# E2E 验证 + Plan 模式写初稿设计（存档）

> 记录：全流程端到端测试结论 + 「从知识库提问到初稿结束」的 plan 反问模式设计与修复。

---

## 一、完整用户旅程（端到端已验证可用）

```
输入选题
 → 选题判断（研究空白/可行性报告，诚实锚定文献）
 → 搜索论文（12 源，返回全部可下载）
 → 一键建库（下载全部 + 解析入库，数量一致 + zip 自动下载到本地供用户检索）
 → 知识库提问（agent 只查当前课题的表，带引用）
 → 点「✍️辅助写初稿」
     → 【Plan 反问模式】agent 先提澄清问题（研究问题/目标用途/选哪些文献作参考文献/结构/局限）
     → 用户回答 → 需求累积
     → 循环直到细节追清
     → agent 开始逐节写初稿（引用库内文献 [编号] + check_draft_quality 自检）
     → 自检通过 → 交付初稿
 → 导出 DOCX/MD/LaTeX/BibTeX
```

## 二、Plan 模式设计（核心差异化）

**目标**：写初稿不是「agent 直接写」，而是「先反问追清细节再分段写」。

### 状态
- `S.writeMode`：是否在写稿 plan 循环中
- `S.writeReq[]`：累积的写稿需求（课题 + 选题判断报告 + 用户的回答）

### 流程
1. 首次点「辅助写初稿」→ `writeMode=true`，注入选题判断报告，提示用户「先确认细节」
2. agent 规则：
   - **无用户回答** → 强制反问（禁止调任何工具，禁止写初稿），返回 3-5 个澄清问题，末尾标记 `【请回答以上问题后继续】`
   - **有用户回答但不足** → 继续反问
   - **已清楚** → 开始逐节写初稿（引用库内文献 + 质量自检）
3. 用户回答 → XX() 检测 `writeMode` → 答案累积进 `S.writeReq` → 重新触发写稿
4. 产出初稿（无标记）→ `writeMode=false` 退出

### 关键实现
```js
// writeDraft: 有回答则可能写，无回答则强制反问
var hasAns = S.writeReq.some(x => x.indexOf('【你的回答】')>=0);
var rule = hasAns
  ? '不足则继续反问，清楚则直接写初稿'
  : '必须先提 3-5 个澄清问题，禁止调工具，禁止写初稿，末尾写【请回答以上问题后继续】';
// PI() 结果处理: 含标记 → 保持反问; 否则是初稿 → writeMode=false
if (S.writeMode && res.indexOf('【请回答以上问题后继续】') < 0) S.writeMode = false;
```

## 三、E2E 抓出并修复的 bug 清单

| Bug | 根因 | 修复 |
|---|---|---|
| 94 篇全量下载太慢 | 下载并行但进度卡 0/N；PDF URL 慢源拖 batch | 分批下载逐批更新进度 + 并发 6 + 超时 20s + 下载上限 500 |
| 建库数量不一致（49 vs 19）| 前端截断 30 + 消息用错计数 | 移除截断下载全部 + 消息「从 N 篇可下载中成功解析 M 篇」|
| agent 答案泄漏 `<tool_calls>` XML | 模型偶发文本输出工具调用，流式捕获 | 正则过滤 |
| DeepSeek 400「reasoning_content must be passed back」| **主循环 LLM 调用缺 `thinking disabled`** → flash 产出推理内容 → 下一轮要回传 | 全链路一致禁 thinking + 捕获回传 reasoning_content（plan/直答/工具轮）|
| 写初稿步数不够 | 逐节 agent_ask 烧光 15 步 | 步数 15→30 + 提示词「一次查全直接写」|
| 第一次写初稿直接写（不反问）| 提示词「清楚就写」让 agent 跳过反问 | 强制「无用户回答必须先反问」|
| 反问阶段还查库（慢）| agent 把「理解课题」理解成查库 | 澄清阶段「禁止调用任何工具」|

## 四、诚实说明

1. **写初稿耗时 1-3 分钟**：DeepSeek API 延迟 + agent 查库 + 自检修订，属固有成本；已优化到最少调用。
2. **上下文链接**：选题判断报告 → 写初稿（注入）；建库 → 写初稿（agent_ask 查当前库）；用户回答 → 初稿（plan 循环累积）。三步都真链接。
3. **参考文献**：由用户 plan 反问中指定（如「用 RLHF/DPO 相关几篇」），agent 按用户选择构建。
4. **合法**：只处理 OA + 用户上传论文；zip 下载到本地供用户自行检索，不提供盗版源。

## 五、验证方法（可复测）

1. 注册/登录 → 输入选题 → 选题判断
2. 搜索 → 一键建库（看进度逐篇动、zip 自动下载、计数一致）
3. 提问（agent 基于知识库回答）
4. 点「辅助写初稿」→ **确认先反问而非直接写**
5. 回答澄清问题 → 确认 agent 据此写（参考文献用你点名的）
6. 自检通过 → 初稿交付 → 导出
