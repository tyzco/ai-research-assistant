# PaperLink 面试介绍 + 应对提问

> 给面试/答辩用。核心原则：**诚实不虚报，讲清楚「差异化」和「怎么解决的」**。
> 数据只引用可复核的（MRR 0.72 是 43篇/30题基准，如实标注小样本）。

---

## 一、一句话介绍（elevator pitch）

> 我做了 PaperLink，一个面向中文研究者的 AI 学术助手。它不是「又一个搜索框」，而是「研究记忆伴侣」——你输入选题，它先判断这题值不值得做（研究空白分析），再搜索建库、辅助写作，**最关键的是它记住你的选题和论文，每天主动告诉你「你的方向有新进展」**。这是 DeepSeek / 谷歌学术给不了的东西。

## 二、项目定位（为什么是这个方向）

**红海 vs 蓝海**：

| 红海（人人都在做）| 我的蓝海 |
|---|---|
| 搜索/问答/总结（DeepSeek/Elicit/Consensus）| **记忆 + 主动推送** |
| 用户问 → 系统答（无状态）| 系统记得你是谁、你的选题、主动推你该读的 |
| 护城河 = 模型（会被降价抹平）| 护城河 = **数据**（越用越值钱）|

**完整闭环**：输入选题（钩子）→ 研究空白报告 → 搜索建库（私有记忆）→ 自动订阅 + 每日检索新进展 + 主动推送。

## 三、技术栈与架构亮点（可讲深）

- **栈**：FastAPI + LanceDB(向量+FTS双层) + SQLite + 本地 bge 嵌入 + DeepSeek（flash 主 + pro 兜底）
- **三层意图漏斗**：规则关键词 → 嵌入语义 margin → LLM+工具（逐层降本，语义层失效降级为规则）
- **自适应混合检索**：BM25 + 向量 RRF 融合（按问题特征动态调权重）+ 两级级联重排（MiniLM → bge-reranker）+ 双语重排 + 引用对数提权
- **自我进化三环**：P1 反思（生成→自批判→修订）/ P2 反馈教训（低分→LLM提炼注入）/ P3 技能记忆（成功模式跨会话）
- **LLM 容错**：超时 + 指数退避重试 + 降级模型（flash 失败自动降 pro）
- **防幻觉**：1M 上下文窗口 + key_findings 证据保留 + 初稿质量清单 + 答案带真实引用
- **安全**：学术白名单闸门（三层漏斗锁定论文用途）+ SSRF 防护 + 路径穿越防护 + topic 级多租户隔离

## 四、应对提问（面试高频 + 你被问倒过的问题）

### Q1：你的数据和知网/谷歌学术比，覆盖不全，价值在哪？
**答**：我不拥有完整学术库，也不需要——竞品也没人自建库，Elicit/Consensus 底层就是 Semantic Scholar 免费 API，都站在**开放学术图谱**（OpenAlex/S2/Crossref/arXiv）上。我的差异化不在「数据全」，在「**记住你的数据**」——用户从学校知网下论文，我索引成他的私有库，还主动推新进展。这是全局库做不到的。

### Q2：你的回答不如直接问 DeepSeek 网页版，凭什么用你？
**答**：这个对标是错的。DeepSeek 网页版会答你「问了什么」，但**不会记得你的选题、更不会主动告诉你「昨天你的方向发了 55 篇新论文」**。我的价值是记忆 + 主动推送 + 真实文献锚定（不编造引用），不是通用问答——通用问答我打不过大厂，也不该打。

### Q3：检索质量怎么保证？
**答**：自适应混合检索（BM25+向量，按问题长度/是否含英文缩写动态调权重）+ 两级级联重排 + 双语重排（中文 query + 英文关键词）+ 引用对数提权（让长尾论文浮出）。基准 MRR 0.72 / R@top5 0.78（**43 篇/30 题/5 主题的小样本，是 sanity 不是大规模性能声明**）。

### Q4：Agent 会不会死循环/长任务跑偏？
**答**：Hook 生命周期（max_steps 步数守卫 + 工具白名单 + 敏感词拦截）+ 反思重试（直答后自批判，不足则修订，有界1次）+ **可选 plan 阶段**（长任务先让 LLM 拆 3-6 步计划再执行，防纯 ReAct 跑偏）。

### Q5：安全怎么做的？
**答**：学术白名单闸门（三层漏斗，锁定用户只能问论文/学术问题，防白嫖算力）+ SSRF 防护（fetch_url 公网 host 校验 + 禁重定向）+ 路径穿越防护（下载/读文件限制在目录内）+ topic 级多租户隔离（凭 topic_id 越权读他人课题会 403）+ LLM 错误不泄露内部细节。

### Q6：自我进化怎么实现？
**答**：三环——P1 反思（生成→自批判→修订）、P2 反馈教训（低分反馈→LLM 提炼教训→注入下次 prompt）、P3 技能记忆（成功任务做法跨会话复用）。**安全约束：Agent 从不改自己的代码/prompt，学习结果人类审批**。

### Q7：为什么用本地嵌入模型，不用云端 API？
**答**：零成本 + 隐私（用户论文不出本机）+ 离线；代价是质量略低，但双语重排 + 重排模型兜底。

### Q8：这个项目最难/最得意的技术点是什么？
**答**（诚实选一个讲深）：**检索质量**——「不常见选题」（如可微神经架构搜索）要浮出关键论文，靠双语重排 + 引用对数提权 + 领域联想词 + CN→EN 兜底解决了；配合 4096 大块分片（LongRAG 思路）覆盖更全。

### Q9：如果给你时间，最想改进什么？
**答**：多租户 agent 链的完整隔离（当前 HTTP 层已隔离，agent 工具链的 user 上下文穿透还没做完）；以及真实用户数据积累后，把 P2/P3 的 bigram 记忆升级成向量检索。

## 五、诚实底线（面试别踩）

1. **别说「我能替代知网/谷歌学术」**——覆盖不全，说「开放图谱 + 私有库」。
2. **别说「回答比 DeepSeek 好」**——说「DeepSeek 给不了的：记忆 + 主动推送 + 真实引用」。
3. **别说「MRR 0.72 是大规模性能」**——说是「43篇/30题小样本 sanity」。
4. **别提 Sci-Hub/盗版**——合法红线，只 OA + 用户上传。

> 一句话总结面试立场：**「我不跟大厂拼通用问答，我拼大厂做不到的——记住你的研究、主动告诉你该读什么。」**
